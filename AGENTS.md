# Agent Rules & Permanent Workflow Guidelines

## 1. Mandatory GitHub Automatic Sync Rule
- **Scope**: Every project and subfolder under `Ai Agent` (e.g. `Trozan Blaze` and any future project).
- **Core Directive**: Whenever ANY change happens (new code, bug fixes, updates, feature implementations, or refactoring), it must automatically be committed and pushed to its corresponding GitHub repository under `SyedTalha561`.
- **New Projects**: If no GitHub repository exists yet for a project, initialize git immediately, establish clean repository structure, configure remote, and push.
- **Cleanliness & Organization**:
  - Always write clean, descriptive commit messages.
  - Maintain a clean working directory (remove scratch/temporary files).
  - Include `.gitignore` and comprehensive `README.md`.
  - Always push to `origin/main` so the remote repository is continuously up to date.
